## Featured Projects

<details open>
<summary><b>BTC Sentinel: Bitcoin Network Intelligence Platform</b></summary>

<br/>

Offline investigation platform built for **Smart India Hackathon, PS 26146**. It ingests CSV, JSON and XML network records and correlates them with on-chain Bitcoin transactions, enriched with local GeoIP/ASN data.

| | |
|:--|:--|
| **Stack** | Python, FastAPI, scikit-learn, NetworkX, DuckDB, React, TypeScript, Tailwind CSS |
| **Scale** | 48,000-observation synthetic benchmark |
| **Performance** | All top-10 ranked leads were planted scenarios (100%, average precision 1.00 at K=10; synthetic data) |
| **Security** | Fully offline with no cloud dependencies; local GeoIP/ASN enrichment |
| **Impact** | Ranked, explainable investigative leads from combined ML and rule-based detection |
| **Repository** | [github.com/shivam123yadav](https://github.com/shivam123yadav?tab=repositories) |

IPs, wallets and transactions are modeled as a graph. Isolation Forest, DBSCAN and rule-based detectors are combined to surface peeling chains, mixing-like flows and repeated fan-out patterns.

</details>

<details>
<summary><b>AgiesAI Sentinel: AI Data-Loss-Prevention Platform</b></summary>

<br/>

A platform that detects sensitive data in text sent to generative AI tools and enforces configurable policies on every event.

| | |
|:--|:--|
| **Stack** | React, TypeScript, Tailwind CSS, FastAPI, Pydantic, MongoDB, Pytest |
| **Scale** | REST API covering detection, incidents, policies, employees and audit logs |
| **Performance** | Each event assigned a 0-100 risk score |
| **Security** | Detects API keys, PII, credit card numbers and cloud tokens; policy actions block, redact, warn or log |
| **Impact** | Incident tracking, employee risk and policy management in a single dashboard |
| **Repository** | [github.com/shivam123yadav](https://github.com/shivam123yadav?tab=repositories) |

A configurable policy engine maps risk levels to actions. The React and TypeScript dashboard (Recharts) is backed by Pytest suites for the detection, risk and policy engines.

</details>

<details>
<summary><b>Trustify: AI Phishing and Malware Detection</b></summary>

<br/>

A web app that uses the Google Gemini API to analyze URLs, emails and files for phishing and malware, with authentication and a results dashboard.

| | |
|:--|:--|
| **Stack** | Flask, MongoDB Atlas, Google Gemini API, Gunicorn, Render |
| **Scale** | Live deployment usable by anyone online without setup |
| **Performance** | Gemini-backed analysis across URLs, emails and files |
| **Security** | Environment-based secrets and secure session cookies |
| **Impact** | Accessible threat checking with persistent user results |
| **Repository** | [github.com/shivam123yadav](https://github.com/shivam123yadav?tab=repositories) |

Application data is stored in MongoDB Atlas and the service is deployed on Render behind Gunicorn.
